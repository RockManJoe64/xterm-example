# xterm-example
An example web app using [xtermjs](https://xtermjs.org/).

* This app uses [pnpm](https://pnpm.io/) for dependency management. 
* It also uses [Parcel](https://parceljs.org/) to test and build.
* In the future may switch to using [Volta](https://volta.sh/)

To start the app, run the command 
```bash
pnpm run start
```
